# Curso Peugeot JTEKT / Koyo

Landing page da Oficina Eficiente, baseada no visual do curso Fiesta e no conteúdo da transcrição Subtitle 1(6).srt.

## Publicação

Conecte este repositório a um projeto Cloudflare Workers e use `npx wrangler deploy`. A pasta `public` também pode ser publicada diretamente em uma hospedagem estática.

## Inscrições

Os três botões abrem o formulário AtendeIA do Peugeot. Confirme o checkout Eduzz no painel do formulário e valide o redirecionamento após publicar. Preço, parcelamento, prazo de acesso, certificado e suporte precisam ser confirmados para este curso.
