# Curso Peugeot JTEKT / Koyo

Landing page da Oficina Eficiente, baseada no visual do curso Fiesta e no conteúdo da transcrição Subtitle 1(6).srt.

## Publicação

Conecte este repositório a um projeto Cloudflare Workers e use `npx wrangler deploy`. A pasta `public` também pode ser publicada diretamente em uma hospedagem estática.

Domínio: https://peugeot.oficinaeficiente.com.br/

## Inscrições

Os três botões abrem o formulário AtendeIA do Peugeot, com checkout Eduzz confirmado pelo responsável pelo curso. A oferta é de R$ 89,00 à vista ou em até 12 vezes, com acesso por 1 ano, certificado mediante solicitação e suporte pelo WhatsApp e pela Eduzz.
